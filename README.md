# zhang-beihai-perspective
章北海思维框架 Skill
基于刘慈欣《三体Ⅱ·黑暗森林》中的章北海，提炼长期危机判断、战略备份、能力建设和行动时机的思维框架。包含小说剧透。
使用
将此仓库目录放到 Codex 的 skills 目录中，目录名为 zhang-beihai-perspective。
调用示例：“用章北海视角分析这个长期决策。”
SKILL.md 是入口，references/research 保存依据、决策案例与验证记录。现实建议为框架推断，不冒充原著立场。
